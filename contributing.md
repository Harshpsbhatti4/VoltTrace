
# Contributing to VoltTrace

Thank you for your interest in contributing to VoltTrace! We welcome contributions to firmware, edge ML models, hardware design, and documentation.

---

## Code of Conduct
By participating in this project, you agree to maintain a respectful, constructive, and collaborative environment.

---

##  How to Contribute

### 1. Reporting Issues
* Check existing issues to see if your bug or feature request has already been reported.
* Open an issue with a clear title, description, and steps to reproduce (or hardware configuration details if applicable).

1. Fork the repository and create a feature branch:
